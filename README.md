# Omdena-Iryss: Proactive Financial Planning for Lung Cancer Patients through Machine Learning-based Cost Prediction

Preprocessed New York Hospital Inpatient Discharges (SPARCS De-Identified) data and built a Streamlit app with a Python-based ML model to predict Healthcare costs associated with Lung Cancer diagnosis. Achieved 84% accuracy on the final model, which included 35,586 observations.

- Version Aug, 2023 - `app` folder: Streamlit app with Python-based ML model
- Version Jun, 2025 - `financiallungcancer_v1.ipynb` file: Implemented on Azure Databricks (MLflow)
- Version July, 2025 - `streamlit_app_snowflake` folder: Implemented on Snowflake
- Version Feb, 2026 - `streamlit_app_refactored` folder: Streamlit app Refactored with Claude (browser-based interface)
- Version Feb, 2026 - `streamlit_app_optimized` folder: Streamlit app Optimized with Claude using PySpark and Parque data format
